# Veda Technology Business & Service Analytics

Major Project — Data Science Track

## Objective
Analyze simulated business and service data covering website visitors, internship applications, training programs, IT service inquiries, customer requests, marketing channels and revenue.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter, Excel, Power BI, SQL and Git/GitHub.

## Deliverables
- Data cleaning and preprocessing
- Exploratory data analysis
- Website visitor analysis
- Internship and training analysis
- IT/service inquiry analysis
- Customer segmentation
- KPI/revenue analysis
- Predictive modeling
- Business recommendations
- Final project report

## Run
pip install -r requirements.txt
python veda_business_service_analytics.py

Dataset is synthetic and created for educational purposes.
